# Design fonts

Newsreader Italic is Gallery’s optional display typeface (ADR 0004 R10/R11,
D5). Only `gallery-gtk` loads the file. Contacts, Music, and
`shell-kit-gtk` must not name the family.

Downloaded from the Google Fonts OFL Newsreader tree. Do not invent a TTF.
